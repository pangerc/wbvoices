# Mixer Epic — Alignment Diff

**Epic:** Audio Mixer (industrialization team)
**Decomposed into tickets:** AAC-30, AAC-36 → AAC-44 (10 tickets)
**Compared against:** `mixer-version-stream` branch (v3.5 stages 1–8d, see [`version3-5.md`](./version3-5.md) → "Mixer redesign — version stream architecture")
**Audit author:** architecture-strategist agent
**Date:** 2026-05-04

This doc compares the industrialization team's epic + decomposed tickets against what we actually shipped on the `mixer-version-stream` branch. It identifies (a) ticket-by-ticket alignment, (b) architectural conflicts where the epic's mental model diverges from ours, (c) prioritized close-the-gap roadmap, and (d) capabilities we shipped that aren't on the epic but are load-bearing.

---

## Two structural framings up front

### 1. DAW vs. constraint-graph mental model

The epic and tickets assume a **DAW-style free-drag-with-snap-guides + scissors-tool + duplicate** paradigm (Logic / Reaper / Audition). What we shipped is a **5-primitive anchor graph with provenance**:

- `absolute(t)` / `relativeTo(slot, edge, offset)` / `simultaneousWith(slot, alignment)` / `atFraction(slot, f)` / `anchorChain`
- `layout: "overlay" | "push"` per anchor
- `origin: "llm-seed" | "user-edit" | "system-default"` per anchor

These don't reconcile by feature work alone. Specifically:

- **Cross-track move (AAC-36):** structurally impossible. Stream type lives on the stream (voice / music / sfx), not on the slot. A voice clip cannot become a sfx clip via drag. Lifting type onto the slot would require refactoring anchor seeds, lint, tag-weaver, and voice-provider routing. **Recommendation: drop cross-track-move from scope; UX should disable it.**
- **Voice clip splitting (AAC-38):** model-hostile. A split voice clip has no slot identity — the second half cannot inherit the original's `slotId` because anchor refs to it become ambiguous. To make voice splits work would require sub-slot identity (`slotId#segment`), virtual slots the resolver expands, or treating split as server-side regenerate of two voice clips with derived scripts. None is cheap. **Music/sfx splitting is tractable.**
- **Free position only via `absolute(t)`:** holding `opt`/`alt` on drop forces absolute. Otherwise drops materialize into a relational primitive. This is intentional — relational anchors survive regeneration; absolute positions don't.

### 2. Generative vs. ingestion product shape

**AAC-43 (drag-and-drop file upload onto timeline)** presupposes user-supplied audio. Our product is generative — every stem comes from a provider (ElevenLabs / Loudly / Mubert / Lahajati / Qwen / ByteDance / OpenAI). There is no ingestion path.

Closing this requires a product-level decision (do we accept user audio at all?), plus an ingestion pipeline (loudness measurement on ingest, PII / legal review for what users upload, a new `userClip` stream parallel to existing voices/music/sfx). **This is not engineering scope — push back to industrialization that the ticket is mis-routed.**

## Things in the epic / tickets that may be missing from the diff

If the epic has tickets for these and we missed them, flag for inclusion. If it doesn't, they're gaps in the epic itself:

- **Undo/redo within a draft.** v3.5 stage 9 list explicitly defers this. Producers will ask for Cmd-Z.
- **Multi-clip selection + group move.** `anchorChain` primitive supports it; UI doesn't.
- **Yellow halo on fragile / orphaned anchors.** Resolver flags exist; UI affordance unbuilt.
- **Head trim for non-voice clips.** Today sfx/music trim only from the right edge.
- **Reset-to-seed UI affordance per anchor.** Shipped, but worth flagging — it's a non-DAW-paradigm capability the epic almost certainly didn't account for.
- **Loudness target update to −14 LUFS / −1 dBTP.** Currently −16 / −2 for AAC-encode headroom. Held pending validation.

## Summary recommendation to industrialization team

1. **Confirm AAC-41 (zoom) as Highest.** Ship first — biggest UX unlock, lowest cost.
2. **Reframe AAC-37.** Mute/solo shipped. Per-clip dB trim shipped. **Static `gainDb` per clip** is the next valuable step (cheap). **Automation curves are stretch, not Highest.**
3. **Reframe AAC-36.** Drag-to-reposition shipped. Visual snap guides are polish, not Highest. **Drop cross-track-move from scope** — structurally wrong.
4. **Split AAC-44 into 44a (pin) and 44b (track-fader-strip).** Accept 44a; decline 44b unless industrialization demonstrates a workflow kebab can't satisfy.
5. **Decline AAC-43 as engineering scope.** It's a product decision about generative-vs-ingestion shape.
6. **Accept AAC-38 only for music/sfx scope.** Voice mid-word splice is hostile to the model; "voice is regenerate, not edit" is a deliberate v3.5 stance.
7. **Acknowledge "shipped beyond scope" capabilities** (slot IDs, anchor graph, mixer version stream, takes lifecycle, LUFS pipeline, etc.) in the epic — they're load-bearing for what the product actually does and constrain what "alignment" means.
